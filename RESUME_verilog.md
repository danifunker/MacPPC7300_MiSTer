## Rules

- SystemVerilog is fine, limited to what Verilator 5.020 and Quartus 17.0 both accept. Keep the RTL clean under Verilator `-Wall` (`make -s lint` in `verilator\`). What Quartus 17 has refused so far: a second read expression on a memory (it becomes flip-flops), byte-enabled writes to a wide array (flip-flops again; `DSPPC604_cache_ram` is eight word RAMs with a write enable each, the shape it infers), a variable part-select of a two-dimensional array (flatten first), `genvar` declared inside the `for`, and a generate loop without `generate`/`endgenerate`; and, found this session, every RAM style attribute (`ramstyle = "MLAB"`, `no_rw_check`, the pragma form, the qsf assignment: all ignored), a three-input add written as one expression (two adders in series; write the 3:2 compression and one adder), and a RAM written from registers whose read is combinational (pass-through logic appears; write the read synchronously).
